# 38. R2 출처와 확인 범위

확인일 2026-09-16. 날짜 없는 도움말의 게시일을 추정하지 않는다. 공식 가이드의 기능 설명과 이 문서의 편집 가설을 구분한다.

| 자료 | 사용 범위 | 확인 한계 |
|---|---|---|
| NAVER SearchAdvisor 콘텐츠 권장 사항 | 독자 가치·운영자 관점·읽기 쉬운 구조·정확한 제목 | 웹 검색 가이드, 홈피드 랭킹 명세 아님 |
| NAVER SearchAdvisor 스팸 사례 | 특정 기술만으로 판단하지 않음, 템플릿 양산·기계적 재작성 경계 | AI 원고의 실제 노출 확률을 제공하지 않음 |
| NAVER 홈피드 소개 | 개인화와 인기 피드 구분 | 전국 동일 순위·CTR·조회 예측 자료 아님 |
| NAVER Datalab API | 상대값·요청 조건·시간 단위 | 실제 API를 호출해 새 추세를 수집하지 않음 |
| Google 포토 공간 확보 | 기기 사본 제거와 이후 접근 방식 | 실제 사용자 기기를 조작하지 않음 |
| Google 포토 백업 | 앱 표시와 백업 구분·계정 확인 | Android 기준 공개 자료, 모든 OS 동작 일반화 금지 |
| Google 포토 삭제 도움말 | 검색 발췌만 확인 | 전체 재열기 실패, 샘플 핵심 근거에서 제외 |
| Microsoft USB-C 문제 해결 | DisplayPort 대체 모드 호환성·점검 | 특정 장비 고장·실험 결과를 확인한 것은 아님 |
| VESA FAQ | 지원 포트와 영상 연결 조건 | 구형 규격 속도 수치를 최신 최대값으로 사용하지 않음 |
| USB-IF PD 설명 | 전력 전달과 영상 조건 구분 | 케이블 상품 추천이나 실물 시험 아님 |

전체 URL·기관·문서 제목·확인일은 `contracts/r2/sources.json`에 있다. 이번에는 글쓰기 품질 개정을 위해 해당 공식 자료를 확인했으며 유튜브·SNS 트렌드 전수조사를 새로 수행했다고 주장하지 않는다. 이전 버전의 영상 분석은 기존 조사 기록으로 유지하되 최신 실증으로 재분류하지 않는다.

## 문서의 사실 분류
- 공식 문서의 설명: 출처 ID와 범위를 표시.
- 설계자의 판단: ‘초기 제안’, ‘편집 판단’, ‘가설’로 구분.
- 계산 예: 실제 관측과 섞지 않고 가상 입력·조건 명시.
- 구현·검사: 실제 명령 결과만 기록.
- 미실행: NOT_RUN 유지. 코드 통과로 대신하지 않음.
