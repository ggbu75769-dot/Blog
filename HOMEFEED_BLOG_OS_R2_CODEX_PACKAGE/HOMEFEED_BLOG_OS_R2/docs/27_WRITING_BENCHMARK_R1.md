# 27. 바로 게시할 수준의 원고 평가 — R1

## 평가를 둘로 나눈다
TRACK A 기획평가: 동일 사건과 동일 자료예산에서 어떤 질문을 선택하는지 비교한다.
TRACK B 집필평가: 동일 브리프·동일 근거·동일 문체프로필·동일 이미지 자산을 고정하고 집필/편집 버전만 바꾼다.
다른 소재와 다른 원문으로 만든 두 글을 비교해 문체모델 개선이라고 결론내리지 않는다.

## 세 기준선
B0: 사실·출처 조건을 지키는 단일 통과 초안.
B1: 기존 final.1의 내용→문체→재검수 흐름.
B2: R1의 기획경쟁/역방향 첫화면 검수/반복제거/변경된 사실 재대조 흐름.
B0도 가짜 체험이나 허위정보를 허용하는 나쁜 원고로 만들지 않는다. 같은 자료와 비용제약에서 비교한다. baseline을 의도적으로 형편없게 만들어 R1 승률을 부풀리지 않는다.

## 실제 사람 평가표
| 차원 | 1점 | 3점 | 5점 |
|---|---|---|---|
| 첫 화면 | 무엇을 답할지 불명확 | 대상과 방향은 이해됨 | 제목의 기대와 새 답이 즉시 연결됨 |
| 새 정보 | 요약·재작성뿐 | 일부 추가 설명 | 독자 질문에 유의미한 근거·비교·해석 |
| 자연스러움 | 기계적 도입·불필요한 반복 | 읽히나 일부 수정 필요 | 해당 블로그다운 흐름, 수정 거의 없음 |
| 관점 | 말투만 다름 | 특정 판단기준 일부 드러남 | 글 전체가 같은 독자의 판단을 일관되게 도움 |
| 완결성 | 답·사진·출처 누락 | 대부분 갖춤 | 텍스트·이미지·표·캡션·출처와 예외까지 사용 가능 |

평가자는 어떤 버전인지 모르게 제시하되 A/B 순서를 무작위로 바꾼다. 초안의 근거·권리 검토는 별도 화면에서 수행한다. 평가 중 수정한 내용과 걸린 시간을 기록한다. 원고 자연스러움, 클릭 의향, 사실성은 다른 항목이다. 클릭 의향이 높아도 기대를 오해시킨 카드는 실패다.

## 초기 평가 표본
채널2개·형식3개·사건그룹10개 이상에서30편을 제안한다. 유효한 평가 단위와 선정 방법을 실행 전에 고정한다. 실패한 자동출력·출고 보류·반복수정도 denominator에 포함한다. 생성 후 잘된 글30편만 뽑지 않는다. 사람2명이 독립 채점한 원점수와 합의점수를 따로 남긴다. 실제 시행 전에는 결과값을 비워 둔다.

## 수용 기준 — 초기 운영 가설
중대 사실 오류/가짜 체험/필수 자산 누락0건. 자연스러움 중앙값4/5, 개별3미만은 보완. 사용자 수정시간 중앙값5분 이내를 목표로 하되 실제 난이도별로 별도 집계한다. 기획 B2 선호·집필 B2 선호는 신뢰구간과 동률을 보고하며 작은 차이를 확정 승리라 하지 않는다.

표본30편에서 오류0건이라는 것은 오류율0%를 증명하지 않는다. 독립 동일분포를 가정한 단순 이항모형의 one-sided 95% 상한도 `1 - 0.05^(1/30)`으로 약9.5%다. 실제 글은 같은 사건·자료를 공유하므로 독립성도 약할 수 있다. 이를 숨기지 않고 운영 중 정정률을 계속 기록한다.

## 24개 평가 시나리오
계약 데이터 `contracts/editorial_benchmark_cases.json`에 24개 시나리오를 정의한다. 수요부재, 실제 새 기능, 반올림 수치, 과거 사건 재게시, 인터뷰 맥락, 영상 미관찰, 체험자료 유무, 표/이미지 누락, 문체반복, 제목수치 불일치, 개인 기억 범위, 만료 전 게시불가, 사용자 현장수정, 통계 지연 등을 포함한다. 이 목록은 실제 콘텐츠 평가를 이미 수행했다는 결과가 아니다.

## 계속 개선할 때의 종료
한 수정라운드당 수정 가설을1~2개로 제한해 원인을 추적한다. 재생성으로 점수만 올리는 방식은 피한다. 실패를 축소하거나 기준을 완화해 통과시키지 않는다. 정해진 비용/횟수에서 더 개선하지 못하면 NEEDS_REVIEW로 넘기고 다른 원고를 진행한다. 실제 운영의 완벽을 선언하지 않고 검증 가능한 릴리스 범위를 명시한다.


## R2 보완 우선 적용
내용·문체·독자 평가·독자용 출력의 상세는 docs/31~38을 함께 적용한다. 특히 부족한 내용은 문체로 덮지 않고 조사/재기획하며, 최종 본문의 실제 payoff 구절과 review 버전을 연결한다. R1 사실·권리·scope·최신성 gate는 약화하지 않는다. R2 예제는 인간평가·실제 에디터·트렌드 효과가 확인되지 않은 편집 기준용 원고다.
