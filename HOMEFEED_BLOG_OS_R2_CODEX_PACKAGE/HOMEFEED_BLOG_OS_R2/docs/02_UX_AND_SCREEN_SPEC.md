## 원고 상세의 레이아웃
상단: 블로그명/원고 버전/마지막 확인 시각/상태. 중앙 70%: 실제 읽을 원고. 우측 30%: 복사·파일·삽입 순서·다음 조치. 내부 기획·검수는 두 번째 탭이며 공개 본문 영역에 섞지 않는다. 모바일에서는 읽기 영역 다음에 도구를 배치한다. 버튼은 ‘AI 재작성’ 대신 ‘도입을 짧게’, ‘근거 재확인’, ‘이 문단만 수정’처럼 영향 범위를 표시한다.

## 복사·전송 UX
전체 복사는 text/plain을 항상 제공하고, 지원되는 자체 웹환경에서 text/html도 함께 쓴다. 사용자의 클릭이 있어야 실행하며 HTTPS/클립보드 권한 실패 시 텍스트 선택과 파일로 대체한다. 로컬 이미지의 자동 복사 보존은 보장하지 않는다. 네이버에는 블록별 복사와 실제 이미지 다운로드를 기본으로 제공한다. 본문에 [이미지 삽입] 같은 작업 문구를 넣지 않고 옆의 전송 가이드에서만 위치를 보여준다.

## 상태와 상호작용
버튼 처리 중 중복 클릭은 동일 idempotency key로 묶는다. 편집 저장에는 revision ETag를 사용해 409 충돌 시 비교 화면을 연다. 취소는 이미 확정된 비용을 삭제하지 않는다. SSE 재연결 후 누락된 상태를 서버에서 다시 조회한다. 화면에서 파생한 상태와 서버의 상태가 다르면 서버를 기준으로 표시한다.

## 접근성·시각 인수
본문 미리보기 360/390/768/1440px에서 확인한다. 200% 글자 확대에서 버튼과 본문이 겹치지 않는다. 표는 모바일 카드로 변환 가능한 구성만 허용하고 표 정보를 이미지로만 제공하지 않는다. 키보드로 주요 동작을 완료하고 상태를 색상만으로 표현하지 않는다. 이미지 대체 설명과 실제 캡션을 구분한다. 출처 링크는 링크 텍스트로 목적을 설명한다.

## 예외 문구 예시
‘자료가 부족합니다’ 대신 ‘직접 사용했다는 표현을 뒷받침하는 기록이 없습니다. 공개 규격 비교글로 바꾸는 대안을 준비했습니다.’
‘완료’ 대신 ‘원고·사진 준비 완료 / 네이버 입력은 아직 확인하지 않았습니다.’
‘홈판 실패’ 대신 ‘해당 관측 표본에서 카드를 확인하지 못했습니다. 전체 추천 미노출을 뜻하지 않습니다.’
